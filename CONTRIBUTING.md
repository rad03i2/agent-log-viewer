# Contributing

Contributions are welcome when they keep the project small, local-first, and testable.

1. Fork the repository and create a focused branch.
2. Use Python 3.10+ and avoid unnecessary runtime dependencies.
3. Install with `python -m pip install -e .`.
4. Run `python -m unittest discover -s tests -v`.
5. Add tests for behavior changes and update both README language sections when user-facing behavior changes.
6. Never commit real agent logs, credentials, API keys, tokens, or personal data.
7. Open a concise pull request explaining the problem, approach, and validation performed.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
